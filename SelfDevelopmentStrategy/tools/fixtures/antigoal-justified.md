# Conventional curricula, challenged

## Do I need LeetCode?

NO — conditionally. The funnel is cold outreach to companies buying AI engineering
capability, evidenced by portfolio artifacts, and nobody in that funnel runs a
whiteboard algorithm screen. LeetCode is therefore deferred, unless the month-12
decision turns toward a large-company role with an algorithmic screen — which
would itself be the justification the ban is conditional on.

## Do I need Kubernetes?

NO. There is no surface: one node, one Postgres, git worktrees. Kubernetes is
deferred at roughly two weeks to learn later, with a real surface, if a client
requires it. Docker is taught narrowly, for Postgres and for the sandbox, which
is the actual operational need.
